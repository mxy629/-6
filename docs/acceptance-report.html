核心闭环

家长发布任务→ 孩子完成任务→ 孩子提交证明→ 家长审核→ 积分到账→ 孩子兑换奖励→ 家长确认

A 账号登录与鉴权

家长微信登录（dev mock）、孩子账号+PIN 登录，返回 JWT；家长可查看归属孩子。

  • 家长微信登录获取 token
  • 孩子 xiaoyu 登录获取 token
  • 家长可看到自己孩子

B 任务发布 → 提交 → 审核通过 → 积分+20

验证积分仅发放一次（幂等），重复通过不再加分，流水仅一条 TASK_REWARD。

  • 家长发布任务成功
  • 孩子今日任务包含新任务
  • 孩子提交任务成功
  • 家长看到待审核任务(SUBMITTED)
  • 家长首次通过任务
  • 已通过任务重复通过幂等(积分不再增加)
  • 孩子积分 +20 (360 → 380)
  • 积分流水仅一条 TASK_REWARD(防重复发积分)

C 驳回 → 重新提交 → 通过(只一次积分)

驳回不发放积分；重新提交并审核通过仅 +10，不重复累计。

  • 家长驳回任务
  • 驳回不发放积分
  • 孩子重新提交成功
  • 重新提交通过后只 +10 (380 → 390)

D 兑换奖励 → 扣积分-200

孩子在奖励商店兑换「看电影一次」(200 积分)，余额相应扣减。

  • 孩子看到奖励「看电影一次」200积分
  • 孩子兑换成功
  • 兑换后积分 -200 (390 → 190)

E 家长拒绝兑换 → 自动退款

拒绝兑换后积分自动退回，流水同时存在 REDEEM 与 REFUND，重复拒绝被拒（幂等）。

  • 家长看到待确认兑换
  • 家长拒绝兑换
  • 拒绝后积分自动退回 (190 → 390)
  • 积分流水同时存在 REDEEM 与 REFUND
  • 已拒绝兑换重复拒绝被拒绝(幂等)
